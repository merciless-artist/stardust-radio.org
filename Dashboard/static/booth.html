LP Quick Reference

Starting an LP

  • !starttracking in the LP channel — start watching that channel for music links
  • !trackingchannels — see which channels are currently being tracked
  • Make sure AzuraCast is up + the stream is live
  • Open this booth → pick your server → members drop song links in Discord → they appear in the queue on the right

During the LP — Booth controls

  • Click a queue row to play that song
  • NEXT — advance to the next queued song
  • BACK — go to the previously played song
  • AUTO ON/OFF — toggles auto-advance when a song ends
  • Type a message in the note bar + POST — shows the note on screen with an aesthetic screensaver behind it (BRB / Stand By / end-of-night)

During the LP — Discord commands

  • !djnote <message> — post a note on the booth screen (same as the note bar)
  • !djclear — clear the current note off the booth
  • !djmenu — show all DJ Booth commands in chat
  • !listsongs — show tracked links so far in chronological order
  • !deletelinks <numbers> — delete specific links from the queue by their list number
  • !ballot — post a voting ballot for songs that have been played

Ending the LP

  • Post a closing note ("Thanks for listening" etc.)
  • !stoptracking — stop tracking the channel
  • !topsongs — read all ballot reactions + announce the top voted songs
  • !exportlinks — export the full queue as a text list (admin)
  • !exporttrp — export Suno/YouTube links as a TRP playlist (admin)
  • !clearlinks — clear all tracked links (admin)
  • × ALL button on the queue — clears the booth queue
  • ✓ PLAYED button on the queue — removes only played songs

Need anything else?

  • !utilitybot — full list of bot commands
  • !utilitybot <command> — details on a single command
  • !linkstats — stats about tracked links
